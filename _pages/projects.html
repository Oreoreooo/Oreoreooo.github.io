MSc Thesis — Student-Facing Modular LLM Agent | Jun. 2026 – Jul. 2026

Built a LangGraph-based agentic AI system integrating RAG, vision-language reasoning, tool calling, and shared-state orchestration to handle student queries and multi-step institutional workflows. Created a 100-scenario evaluation benchmark, achieving 95% intent accuracy, 93.3% workflow-structure accuracy, 97.8% tool-call success, and 81% end-to-end task resolution.

A Survey of Inconsistency in Heterogeneous LLM-Based Multi-Agent Systems | Apr. 2026 – May 2026

Proposed a Cognition–Memory–Action framework to analyze inconsistency across task understanding, shared memory, and action execution in multi-agent collaboration. Reviewed representative mitigation strategies including shared world models, standardized workflows, shared memory, synchronization protocols, conversation orchestration, and transactional tool control.

Multi-modal Motion Generation Pipeline for Embodied AI | Nov. 2024 – Apr. 2025

Developed an end-to-end motion synthesis pipeline using GPT-4o to reason from environment images and generate semantic action sequences. Integrated the CHOIS diffusion framework to transform instructions, environmental context, and planned waypoints into physically plausible 3D human-object interactions, evaluated through Foot Sliding and Waypoint Error.

Dogbot | Mar. 2024 – Apr. 2024

Developed a robot dog on NVIDIA Jetson Nano and Arduino Mega 2560 with ROS 2, featuring obstacle avoidance, autonomous patrol, object detection and grasping, and voice control. Trained an SSD object detector on a custom 100-image dataset and connected Siri and iOS Shortcuts with the Jetson Nano for voice-controlled movement and object retrieval.

Gluttonous Snake | Mar. 2022 – Apr. 2022

Built a C++ interactive terminal game where players control a dynamically growing snake to collect letters and spell words across 10 increasingly difficult levels. Implemented randomized map generation, real-time keyboard input using termios, a modular multi-file architecture, vector-based dynamic memory management, and persistent save/load functionality through file I/O.
